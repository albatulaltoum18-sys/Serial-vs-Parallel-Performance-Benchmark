Serial vs Parallel Performance Benchmark

Project Overview
This project compares the performance of a serial implementation and a parallel implementation of the same computational workload. The goal is to measure execution time and analyze the performance differences using recorded timing results.

Objective
- Run serial and parallel versions of the workload.
- Measure and compare Real Time and CPU Time.
- Analyze performance behavior and report the results.

Project Structure
src/
  - Serial_part.c: Serial implementation.
  - Parallel_part.c: Parallel implementation.
scripts/
  - Scripts used for compiling and running the programs.
results/
  - Output files from serial and parallel runs, including timing measurements.
charts/
  - Excel file containing charts used for visualizing results.
report/
  - Report document explaining methodology and results.

Notes
- The repository includes source code, run scripts, and output results used for analysis.
- Executable files are not required in the repository; source code and results are sufficient.
